# Third-Party Notices

## Leaflet

The optional geographic map uses Leaflet 1.9.4.

Leaflet is distributed under the BSD 2-Clause License. The complete Leaflet license should remain alongside the vendored distribution in `vendor/leaflet/` when the dependency is installed or committed.

## OpenStreetMap

The default basemap requests tiles from OpenStreetMap when the map is displayed. Attribution is displayed by the Leaflet map layer. Deployment should continue to respect the applicable OpenStreetMap tile usage policy.

## No shared toolbox dependencies

This tool does not load CSS, JavaScript, assets, or application libraries from other tools in the `geospatial-tools` repository.
