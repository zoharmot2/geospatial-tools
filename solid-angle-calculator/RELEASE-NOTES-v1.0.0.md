# Solid Angle & 3D Visibility Calculator v1.0.0

## Release status

**Stable**

Version 1.0.0 completes the initial product specification and development plan.

## Included workflows

1. Simple Calculator: cone, circular target, rectangle, sphere.
2. Cartesian Spatial / GIS Calculator.
3. WGS84 geographic Spatial / GIS Calculator.
4. Manual target vertex editing.
5. GeoJSON Polygon import.
6. Interactive geographic map.
7. Interactive 3D observer-target visualization.
8. Numerical interpretation and spatial diagnostics.
9. Copy, JSON export, and shareable URL state.
10. Standalone and `?embed=1` deployment modes.

## Release QA gate

The release is designed to pass:

- mathematical reference tests;
- spatial geometry and coordinate tests;
- share-state tests;
- browser smoke tests for Simple and Spatial workflows;
- standalone and embed-mode checks.
