Geospatial Toolbox

Geospatial Tools

A growing collection of standalone browser-based utilities for geospatial analysis, coordinate transformation, spatial geometry, and related GIS workflows.

Available tools

Each application is self-contained and can be used independently.

Stable Version 2.4.1

Coordinate Converter

Convert individual coordinates or tabular datasets between geographic and projected coordinate reference systems.

  • WGS84, ITM, ICS, UTM, Web Mercator, BNG, Lambert-93, and CRS search
  • CSV and Excel batch conversion
  • Interactive Leaflet map and map-based point selection
  • Reverse geocoding, shareable links, and iframe embed mode
Open Coordinate Converter
Stable Version 1.0.0

Solid Angle & 3D Visibility Calculator

Calculate the solid angle subtended by standard geometric objects or user-defined three-dimensional spatial targets from an observer point.

  • Simple geometry: cone, circular target, rectangle, and sphere
  • Cartesian XYZ and WGS84 geographic workflows
  • GeoJSON Polygon import and interactive geographic target definition
  • 3D observer–target visualization, JSON export, shareable state, and embed mode
Open Solid Angle Calculator

About the toolbox

Geospatial Tools is organized as a single repository containing independent applications. Each tool includes its own HTML, CSS, JavaScript, assets, libraries, documentation, and runtime dependencies. Tools do not depend on shared application files and can therefore be deployed, embedded, tested, or reused independently.
